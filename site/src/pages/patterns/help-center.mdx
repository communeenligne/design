## Démonstrations

Des pages qui ne chargent que le paquet (`@communeenligne/design/index.css` et ses scripts), aucune feuille de ce site : elles reproduisent les maquettes de l'accueil, d'un article, de la page des rubriques et de la page introuvable.

## En-tête

Le modèle [page de documentation](/patterns/documentation-page/#pour-le-centre-daide) sur une seule ligne : le logo, le nom de la section (`cel-doc-header__product`, « Centre d'aide »), puis à droite `cel-doc-header__actions` : les liens (`cel-nav`) et le déclencheur de la [palette de recherche](/components/search/). Sous 860 px, les liens laissent la place au [menu sur téléphone](/components/menu/) ; sous 640 px, le déclencheur passe sur sa propre ligne, pleine largeur. La fenêtre de la palette est à la fin de `<body>`.

## Article

Le modèle [page de documentation](/patterns/documentation-page/), sur trois colonnes :

1. **Navigation latérale** : les rubriques ; la rubrique ouverte (`aria-current="true"`) montre ses articles, l'article en cours porte `aria-current="page"`.
2. **Contenu** : [fil d'Ariane](/components/breadcrumb/), titre, [en-tête d'article](/components/article-meta/), chapô ; puis le texte : [encarts](/components/callout/#dans-un-article) « À savoir » et « Attention », [étapes](/components/steps/#avec-une-capture) avec une capture, [vidéo](/components/video/), [questions](/components/faq/#à-plat) à plat ; enfin l'[avis sur la page](/components/feedback/) et les [pages précédente et suivante](/components/pager/).
3. **Sommaire** : les parties de l'article, celle qu'on lit marquée par `js/toc.js`, et le lien « Dans votre administration » (`cel-toc__related`).

## Scripts

<Code lang="js" code={`import { initTheme } from '@communeenligne/design/js/theme.js'
import { initMenu } from '@communeenligne/design/js/menu.js'
import { initToc } from '@communeenligne/design/js/toc.js'
import { initVideo } from '@communeenligne/design/js/video.js'
import { initFeedback } from '@communeenligne/design/js/feedback.js'
import { initListFilter } from '@communeenligne/design/js/list-filter.js'
import { endpointSearch, initSearch } from '@communeenligne/design/js/search.js'

initTheme({ cookie: 'cel_theme', storage: false })
initMenu()
initToc()          // sommaire : la partie lue
initVideo()        // aperçu et bouton de lecture
initListFilter()   // page des rubriques : filtre par rôle
initFeedback()     // « Cette page vous a-t-elle aidé ? » envoyé à l'action du formulaire
initSearch(document.querySelector('#help-search'), { search: endpointSearch('/aide/recherche'), delay: 200 })`} />

Tout fonctionne sans script : le menu devient une liste, le déclencheur et le champ de la page introuvable mènent à la page de recherche, le filtre par rôle reste masqué (toutes les rubriques s'affichent), la vidéo garde les commandes du navigateur, l'avis est un formulaire, le sommaire une liste de liens.

## Accessibilité

- **Titres :** un seul `h1` (le titre de l'accueil, celui de l'article) ; `h2` pour les bandes et les parties, `h3` pour les rubriques.
- **Repères :** `header`, `nav` nommées (« Centre d'aide », « Rubriques », « Fil d'Ariane », « Sur cette page », « Articles voisins »), `main` cible du lien d'évitement, `footer` ; la palette est une fenêtre modale nommée.
- **Images :** la capture d'écran d'une étape a un texte de remplacement qui dit ce qu'elle montre ; l'illustration et les pictogrammes sont décoratifs ; les vidéos sont sous-titrées et transcrites.
