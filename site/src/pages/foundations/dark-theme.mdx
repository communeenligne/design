## Ce qui change

- **Les couleurs seulement.** Tailles, espaces, rayons et durées sont les mêmes.
- **Les surfaces s'inversent** : la page passe à `#0f1620`, les cartes à `#172230`. Les textes s'éclaircissent pour garder 4,5:1.
- **Le marine devient bleu clair** pour le texte (`--cel-color-primary` : `#a7c9ee`) et plus lumineux pour les boutons (`--cel-color-action` : `#33659a`).
- **Aucune ombre** : les couleurs d'ombre sont transparentes, les bordures suffisent.

## Ce qui ne change pas

Les couleurs posées sur une surface forte (fond marine, forêt) ou dorée restent identiques : texte blanc sur marine, encre sur or, logo pour fond sombre dans le pied de page. Elles sont regroupées dans `foundations/colors.css` sous « same in both themes » (identiques dans les deux thèmes). Une variable qui renvoie à une autre (`--cel-focus-color: var(--cel-color-primary)`) la suit en sombre, sans être redéfinie.

## Écrire une couleur pour les deux thèmes

Toujours une variable de rôle (`--cel-color-text`, `--cel-color-surface`, `--cel-color-primary`), jamais une couleur de marque (`--cel-color-navy`) pour un texte ou un fond de page : la couleur de marque ne change pas en sombre.
