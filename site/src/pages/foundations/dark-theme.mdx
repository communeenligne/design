## Ce qui change

- **Les couleurs seulement.** Tailles, espaces, rayons et durées sont les mêmes.
- **Les surfaces s'inversent** : la page passe à `#0f1620`, les cartes à `#172230`. Les textes s'éclaircissent pour garder 4,5:1.
- **Le marine devient bleu clair** pour le texte (`--cel-couleur-texte-marine` : `#a7c9ee`) et plus lumineux pour les boutons (`--cel-couleur-bouton` : `#33659a`).
- **Aucune ombre** : les couleurs d'ombre sont transparentes, les bordures suffisent.

## Ce qui ne change pas

Les couleurs posées sur une surface forte (fond marine, forêt) ou dorée restent identiques : texte blanc sur marine, encre sur or, logo pour fond sombre dans le pied de page. Elles sont regroupées dans tokens.css sous « identiques dans les deux thèmes ».

## Écrire une couleur pour les deux thèmes

Toujours une variable de rôle (`--cel-couleur-texte`, `--cel-couleur-surface`), jamais une couleur de marque (`--cel-couleur-marine`) pour un texte ou un fond de page : la couleur de marque ne change pas en sombre.
