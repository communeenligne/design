## À quoi il sert

Le bandeau d'aide oriente vers l'aide en ligne sur les pages tarif, fonctionnalités et guides, collé sous l'en-tête de page (un seul filet entre les deux). La variante ocre signale qu'une page n'est pas publiée.

**Quand ne pas l'utiliser :** dans le corps d'une page (prendre l'[encart](/components/callout/)), pour une alerte urgente, ou plusieurs fois sur une page.

## Accessibilité

- **Rôle :** `<aside>` avec un `aria-label` pour le bandeau d'aide ; `role="status"` pour le brouillon.
- **Clavier :** seul le lien est atteignable.
- **Icône :** décorative (`aria-hidden`).
