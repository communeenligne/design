## À quoi il sert

Présenter trois publics ou trois grands usages côte à côte (« Pour la mairie », « Pour les habitants », « Pour les élus »).

## Variantes

`.cel-features` (une liste) range les cartes : trois colonnes égales à partir de 960 px, une seule colonne en dessous, jamais une carte seule étirée sous deux autres. `.cel-feature` est bleue par défaut, `--ocre` et `--vert` pour les deux autres.

## Accessibilité

- Une liste (`<ul>`) : le nombre de cartes est annoncé.
- L'icône est décorative ; le titre dit tout.
