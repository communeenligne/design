## À quoi il sert

Choisir une commune dans la liste officielle (inscription, contact, prix exact sur la page tarif) sans faire défiler 35 000 noms : dès deux caractères, la liste propose les communes qui correspondent.

**Quand ne pas l'utiliser :** pour une liste courte et fixe (prendre la [liste déroulante](/components/select/)) ; pour une recherche dans le texte du site.

## Composition

`.cel-combobox` se pose sur le `.cel-field` lui-même : libellé, `__control` (l'icône `__icon` et le champ `__input`), la liste `__list`, l'aide, une zone `aria-live` masquée qui annonce le nombre de résultats. Chaque résultat `__option` a un nom `__name` et, s'il y a lieu, des précisions `__details` (département, code postal, population).

Les résultats viennent du projet, jamais du script : `search` reçoit le texte tapé et rend une liste d'objets `{ id, label, details }`. La landing interroge sa propre liste (`/inscription/communes`), jamais un service extérieur.

## Script

<Code lang="js" code={`import { initCombobox } from '@communeenligne/design/js/combobox.js'

document.querySelectorAll('[data-cel-combobox]').forEach((element) => {
    const code = element.closest('form').querySelector('[name="insee_code"]')

    initCombobox(element, {
        // Rend [{ id, label, details }] ; signal : la recherche précédente est annulée à chaque frappe.
        search: async (query, { signal }) => {
            const response = await fetch(\`/inscription/communes?q=\${encodeURIComponent(query)}\`, { signal, headers: { Accept: 'application/json' } })
            const { results } = await response.json()

            return results.map((commune) => ({ ...commune, id: commune.code, label: commune.name, details: \`\${commune.department} · \${commune.postal_code}\` }))
        },
        onChoose: (commune) => { code.value = commune.code },
        onInput: () => { code.value = '' },   // le texte changé n'est plus la commune choisie
    })
})`} />

Options : `minLength` (2 par défaut), `delay` (200 ms entre la dernière frappe et la recherche). `initCombobox()` rend `{ clear() }`, pour un bouton « Changer » qui vide le champ et y rend le focus. Les messages annoncés viennent des attributs `data-cel-message-none`, `-one`, `-many` (`#` y devient le nombre), `-selected` (`#` y devient le nom) et `-unavailable`.

## Accessibilité

- **Motif :** combobox de l'ARIA avec liste (`role="combobox"`, `aria-autocomplete="list"`, `aria-expanded`, `aria-controls` ; `role="listbox"` et `role="option"`), posé par le script : sans lui, un simple champ texte que le serveur lit, et la page propose les communes possibles après l'envoi.
- **Clavier :** flèche bas pour ouvrir la liste et descendre, flèche haut pour remonter, Entrée pour choisir, Échap pour fermer ; le focus reste dans le champ (`aria-activedescendant`).
- **Annonces :** le nombre de résultats, puis la commune choisie, dans une zone `aria-live="polite"` ; l'état ARIA change sans attendre la fin du fondu.
- **Libellé :** toujours présent ; masqué visuellement seulement pour le grand champ, dont l'exemple dit ce qu'on attend.
