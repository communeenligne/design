## Le principe

Le thème clair est celui par défaut. Le thème sombre s'active en posant la classe `cel-dark` sur `<html>` : seules les variables de couleur changent, les ombres deviennent transparentes. La préférence du système (`prefers-color-scheme`) n'est jamais lue : c'est le visiteur qui choisit, dans le pied de page.

<Code code={`<html lang="fr" class="cel-dark">`} />

## Rendu par le serveur (landing)

Le serveur lit le choix dans un cookie et pose la classe dès le rendu : aucun clignotement, et le choix fonctionne sans script. Le sélecteur est fait de deux liens qui posent le cookie puis reviennent à la page ; `theme.js` les remplace par des boutons quand le script tourne.

<Code lang="js" code={`import { initTheme } from '@communeenligne/design/js/theme.js'

// Le cookie lu par le serveur, et rien dans le stockage local.
initTheme({ cookie: 'cel_theme', storage: false })`} />

Le cookie suffit : `storage: false` évite d'écrire le même choix dans le stockage local, qu'il faudrait sinon déclarer. Pas besoin de `theme-boot.js`.

## Site statique

Sans serveur pour lire un cookie, le choix est gardé dans le stockage local (clé `cel-theme`), le mode par défaut de `initTheme()`. Charger `js/theme-boot.js` dans `<head>`, sans `defer` : il pose la classe avant le premier affichage si le visiteur a choisi le thème sombre. Puis `initTheme()` branche les boutons.

<Code code={`<head>
    <script src="/design/js/theme-boot.js"></script>
</head>`} />
