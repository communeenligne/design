# Illustrations

Decorative illustrations of Commune en ligne, MIT license (see LICENSE).

- `village.svg`: silhouette of a village (houses, town hall, church), 1440 × 160, a single shape in `currentColor`.

Shown with the `.cel-illustration` class (components/documentation.css), which uses the file as a mask: the shape
takes the text color of its container, so it follows the light and dark themes. As an `<img>`, it is black.
